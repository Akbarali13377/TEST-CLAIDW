# 3D Portfolio

An interactive developer portfolio built with React, Vite, and Three.js
(via `@react-three/fiber` and `@react-three/drei`).

## Features

- Full-screen animated 3D hero scene (floating geometry, starfield, sparkles)
- Smooth scroll-triggered section animations with `framer-motion`
- About, Skills, Projects, and Contact sections
- Tilt-on-hover project cards
- Responsive layout with a mobile nav menu

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Customizing content

All personal content (name, bio, stats, skills, projects, social links)
lives in `src/data/portfolio.js` — edit that file to make the site yours.
